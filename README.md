# دفترچه تلفن با React

این پروژه یک دفترچه تلفن ساده است که با React پیاده‌سازی شده و امکانات زیر را فراهم می‌کند:

## قابلیت‌های اصلی

### ایجاد مخاطب جدید (Create)

- افزودن نام و شماره تلفن مخاطب جدید
- اعتبارسنجی فرم‌های ورودی
- ذخیره‌سازی در localStorage

### نمایش مخاطبین (Read)

- نمایش لیست تمامی مخاطبین
- جستجو در بین مخاطبین
- مرتب‌سازی بر اساس نام

### ویرایش مخاطب (Update)

- امکان ویرایش نام و شماره تلفن
- بروزرسانی اطلاعات در localStorage

### حذف مخاطب (Delete)

- حذف مخاطب از لیست
- حذف از localStorage

## نصب و اجرا

برای اجرای پروژه در محیط توسعه:

npm install
npm start

پروژه در آدرس http://localhost:3000 اجرا خواهد شد.

## تکنولوژی‌های استفاده شده

- React.js
- React Hooks
- localStorage برای ذخیره‌سازی داده‌ها
- CSS Modules برای استایل‌دهی

## ساختار پروژه

- `src/components/`: کامپوننت‌های React
- `src/hooks/`: هوک‌های سفارشی
- `src/utils/`: توابع کمکی
- `src/styles/`: فایل‌های CSS

## نحوه استفاده

1. با کلیک روی دکمه "افزودن مخاطب جدید" فرم مربوطه باز می‌شود
2. اطلاعات مخاطب را وارد کنید
3. برای ویرایش روی آیکون مداد کلیک کنید
4. برای حذف از آیکون سطل زباله استفاده کنید
5. برای جستجو از فیلد جستجو در بالای صفحه استفاده کنید
